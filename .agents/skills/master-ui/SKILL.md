# Master UI Design

Read [references/MASTER_UI_SKILL.md](references/MASTER_UI_SKILL.md) before performing this workflow. It contains the corrected specification derived from the supplied Master UI Design Skill Engineering report.

Honor the user's brief and existing product system. Treat visual defaults as adaptable preferences. Apply accessibility criteria with their actual scope and exceptions. Use current official documentation for version-sensitive APIs; distinguish observed patterns from verified requirements.

For a complete build, use this as the coordinating entry point. For a narrow color, type, component, research, reference, or review request, load only that specialist skill when installed.
This skill does not authorize redesigning unrelated screens, installing dependencies, publishing, or changing backend behavior.

Report what was produced, the decisions that matter, evidence from checks, and any remaining limitations. Never claim a live browser check or standards conformance from source inspection alone.
