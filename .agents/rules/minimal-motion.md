# Minimal Motion Rules
Atlas motion is minimal, calm, smooth and purposeful. Motion communicates hierarchy, continuity or feedback; it is not decoration.

Allowed: subtle opacity/small-distance transitions, short screen and sheet transitions, press feedback, gentle expand/collapse, helpful map camera movement.

Avoid: large parallax, bouncy/overshoot effects, continuous loops, animated backgrounds, animating every list item, long entrance sequences and fake AI progress.

Use consistent tokens; typical micro-interactions 120–200 ms and simple transitions 180–260 ms as starting points, tuned per platform. Respect Reduce Motion. Prefer transform/opacity over expensive layout animation. Test across common desktop and mobile browser viewports.
